# 2D Platformer — Agatha Roman Garcia

* **CMake Version:** 4.3
* **Language:** C++23
* **Physics:** Box2D | **Graphics:** SFML

## Objective
Reach the finish line without touching the moving saws.  
To make the run a bit more forgiving, there is a **checkpoint** halfway through the level.

## Controls
* **Move:** Left / Right Arrows
* **Jump:** Space *(includes coyote time)*
* **Reset Level:** `R`

## Easy Customization
Includes a `settings.h` header file where you can easily tweak parameters like jump force, gravity, and movement speed.
